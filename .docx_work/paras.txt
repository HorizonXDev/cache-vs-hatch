The accompanying website provides visual and interactive explanations to make these concepts easier to understand."
[12] "What problem does this project address?Transformer-based models can require substantial computation and memory when processing long sequences. During autoregressive generation, previously processed information may need to remain available for future tokens. Our project aims to explain this memory challenge and help user understand how KV Cache and BDH approach the processing and retention of information."
[13] "What is a Transformer? "
[14] "A Transformer is a neural-network architecture designed to process sequences using attention mechanisms. It became especially important in NLP (Natural Language Processing) because it can generate relationships between tokens efficiently and can process information in parallel during training."
[15] "Why are Transformers important?Transformers form the foundation of many modern large language models like ChatGPT, Llama etc. Their attention mechanism allows the model to determine how different tokens relate to one another, making Transformers effective for understanding and generating sequences."
[16] "What is a token?"
[17] "A token is a unit of text processed by a language model. Depending on the tokenizer, a token can represent a complete word, part of a word, punctuation, or another piece of text."
[18] "Why does a model use tokens?"
[19] "Neural networks operate on numerical representations. Tokenization converts text into manageable units that can then be mapped to numerical representations and processed by the model."
[20] "What is autoregressive generation?"
[21] "Autoregressive generation is a process in which a model generates a sequence one token at a time, using previously generated tokens as context for predicting the next token."
[22] "Example: “I love” → “I love AI” → “I love AI because…”"
[23] "Each newly generated token becomes part of the context for subsequent predictions."
[24] "What is self-attention?"
[25] "Self-attention is a mechanism that allows a model to determine how strongly different tokens in a sequence should influence one another. It helps the model identify which parts of the available context are relevant when processing a particular token."
[26] "Why is this a problem?"
[27] "Repeatedly computing information that has already been calculated can introduce unnecessary computation. Additionally, storing information for long contexts can consume substantial memory."
[28] "This motivates techniques such as KV Caching."
[29] " What is KV Cache?"
[30] "KV Cache is a technique used during Transformer inference in which previously computed Key and Value representations are stored so they can be reused when generating subsequent tokens."
[31] " Why is it called KV Cache?"
[32] "It is called KV Cache because the cached information primarily consists of the Keys (K) and Values (V) from previous tokens."
[33] " How does KV Cache work step by step?"
[34] "Suppose the model receives:"
[35] "“I love AI”"
[36] "During processing, the model computes Key and Value representations. These are stored in the cache. When the next token is generated: “because”, the model can reuse the previously computed K/V information instead of recomputing the K/V representations for all previous tokens. The cache therefore grows as new tokens are generated."

[45] "What are the main advantages?"
[46] "Reduces redundant computation during autoregressive generation. "
[47] "Improves generation efficiency. "
[48] "Allows previously calculated K/V representations to be reused. "
[49] "Is widely used in Transformer-based LLM inference. "
[50] " Does KV Cache solve every memory problem?"
[51] "No. KV Cache reduces repeated computation, but the cache itself consumes memory. As the context and number of generated tokens increase, the amount of cached K/V information can also increase."
[52] " What is the main trade-off?"
[53] "Less re-computation ↔ More memory usage: KV Cache exchanges additional memory storage for improved inference efficiency."
[54] " What is Dragon Hatchling (BDH)?"
[55] "Dragon Hatchling (BDH) is an architecture that explores a different approach to sequence processing and maintaining information compared with conventional Transformer-based approaches. Rather than simply treating the problem as storing the Keys and Values of all previous tokens, BDH provides an alternative architectural perspective on how information can be processed and retained."
[56] "What is the key difference?"
[57] "KV Cache is a mechanism used with Transformer inference to store and reuse previously computed Key and Value representations. BDH represents a different architectural approach to processing sequential information and maintaining useful internal information."
